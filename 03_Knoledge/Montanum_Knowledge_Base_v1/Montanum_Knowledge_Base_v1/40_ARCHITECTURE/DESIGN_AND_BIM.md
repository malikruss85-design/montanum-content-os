# Architecture and BIM

## Studio method

Montanum combines concept development with technical delivery.

The project is not separated into unrelated images, drawings and engineering packages. The goal is one coordinated design system.

## BIM value

BIM is used for:

- multidisciplinary coordination
- clash reduction
- accurate material quantities
- procurement planning
- budgeting support
- construction documentation
- detail development
- implementation control

## Design standard

A project should be:

- original
- functional
- technically coordinated
- commercially intelligent
- buildable
- visually compelling
- appropriate to climate and location

## Visualization standard

Visualization must communicate a real design, not conceal unresolved architecture.

## Hospitality focus

Hospitality design must address:

- guest experience
- circulation
- privacy
- operations
- service access
- maintenance
- atmosphere
- commercial performance
- marketing value
